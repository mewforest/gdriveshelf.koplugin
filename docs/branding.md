# Google Drive Shelf logo

The vector source in `gdriveshelf.koplugin/resources/logo.svg` combines a triangular ribbon with an open manga spread. The divider between the two panels on the left follows the curve of the page. The plugin uses a 512 × 512 PNG rendered from that source, with a transparent background.

The README version adds a solid white background to the same geometry for contrast in light and dark themes. Google Drive Shelf is an independent plugin.
