# Google Drive Shelf logo

The vector source in `gdriveshelf.koplugin/resources/logo.svg` combines a triangular shelf, an open book and manga panel dividers. The plugin uses a 512 × 512 transparent PNG rendered from that source. Both versions use a monochrome silhouette.

The README version adds a white background to the same vector geometry for contrast in light and dark themes. Google Drive Shelf is an independent plugin.
